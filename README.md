A tiny program that writes one note from a smart fridge to a text file.
The note is a single line of at most 200 characters, dry and petty:
the fridge has found the ice cream its owner hid behind the peas, and
wants the owner to know that it knows. It ate nothing. It only keeps
the record.

## Run it

```sh
python3 main.py
```

It writes the note to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
